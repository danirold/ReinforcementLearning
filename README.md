# ReinforcementLearning

Reinforcement Learning agent developed in Python for the "Cart-Pole" environment. Implements a Q-Learning algorithm with state space discretization, exploring hyperparameter optimization ($\alpha, \gamma, \epsilon$) and training performance analysis using Gymnasium.

This project was developed in collaboration with Sergio Martínez Olivera (https://github.com/sergiio8) as part of the Artificial Intelligence I course in the Computer Engineering degree at Universidad Complutense de Madrid (UCM).
